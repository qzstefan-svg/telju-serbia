| Bestand | Omschrijving |
|---|---|
| `index.html` | De volledige website (één file) |

---

## 🚀 Online zetten via GitHub + Vercel

### Stap 1 — GitHub repository aanmaken

1. Ga naar [github.com](https://github.com) en log in
2. Klik rechtsboven op **"+"** → **"New repository"**
3. Geef het een naam, bijv. `telju-srbija`
4. Kies **Public**
5. Klik **"Create repository"**

### Stap 2 — index.html uploaden

1. Klik op **"uploading an existing file"**
2. Sleep `index.html` naar het uploadvenster
3. Scroll naar beneden → klik **"Commit changes"**

### Stap 3 — Verbinden met Vercel

1. Ga naar [vercel.com](https://vercel.com) en log in met GitHub
2. Klik **"Add New Project"**
3. Kies je `telju-srbija` repository
4. Klik **"Deploy"** — Vercel detecteert automatisch dat het een statische HTML-site is

### Stap 4 — Je link

Na de deploy krijg je een link zoals:
```
https://telju-srbija.vercel.app
```

Deze link werkt direct op elke telefoon en kan je via WhatsApp sturen.

---

## 🔄 Website updaten

Elke keer dat je `index.html` aanpast en naar GitHub pusht, herdeployt Vercel automatisch binnen ~30 seconden.

### In GitHub (makkelijkst)

1. Ga naar je repository op GitHub
2. Klik op `index.html`
3. Klik het potlood-icoon (✏️) rechtsboven
4. Pas de code aan
5. Klik **"Commit changes"** → Vercel update automatisch

## 🛍️ Op Shopify plaatsen

1. Ga naar **Online Store → Pages**
2. Maak nieuwe pagina aan
3. Klik **"<>"** (code editor) rechtsboven
4. Plak de inhoud van `index.html` erin
5. Sla op en publiceer
